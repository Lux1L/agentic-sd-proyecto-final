# Arriendo Familiar · web

Frontend en React + Vite + TypeScript con [Kumo](https://kumo-ui.com) (`@cloudflare/kumo`) y Tailwind v4.

```bash
npm install && npm run dev
```

Abre http://localhost:5173. Requiere la API corriendo en `http://localhost:5080` (el proxy de Vite reenvía `/api/*` quitando el prefijo `/api`).
Credenciales de demo: `admin@arriendo.pe` / `Demo1234!`.

Otros scripts: `npm run build` (typecheck + build) y `npm run lint`.
